## 内容与能力边界

内置 9 本各 180 词精选、805 个去重词；9 本完整源标签词书可按需下载，合计 14,775 个去重词。SAT 尚不可用。实际数量、源文件 SHA 与 MIT 许可保存在 `data/provenance.json` 及下载包内。212 个常用词核心义经过人工选择，其余来自词典首义，不声称逐条人工编审或真题最高频。

默认一个核心义，可展开其他义项及已提供的原创例句。没有例句的词不编造例句。原生端仅提供音标，网页朗读依赖设备语音。首轮未提供自选核心义、拼写听写、用户登录、云同步或拟合 FSRS；后续账号同步已补齐，见末尾。

“不认识”5 分钟、“不确定”15 分钟再见；“认识”仍安排复习，到期回忆成功才逐级延长。提前反复刷认识不能提升稳定记忆等级。产品没有承诺固定保持率或将一次认识视为永久掌握。

完整词库先校验、成功保存后再启用。微信分片存储避免单键大小限制，发生总容量错误时保留原进度；恢复备份先补齐必要词书再替换进度。网页 IndexedDB 无法访问时仍能进入内置精选，无法恢复的原始学习记录会保留以便导出。

## 本轮：学习顺序

首页与设置已加入记忆优先、字母顺序、每日稳定随机三种选择，学习页显示本组顺序。切换下组生效，偏好保存在设备并随 JSON 备份恢复。旧记录自动补为记忆优先，不清空进度或改变主动回忆偏好。

字母与随机均先处理全部未学词池，再按当日剩余额度取词；随机同日重开及评分后保持剩余词相对顺序，次日变化。今日学习的到期复习始终先于新词。记忆优先按相对逾期程度、薄弱反馈和遗忘次数排序，是透明规则，不声称拟合个人遗忘概率。

本轮 `npm run build`、66 项 `npm test`、18 组 `npm run test:browser` 全部通过；原生 23 项包含微信官方编译，320/390px 共 16 个原生源码布局状态通过。新增检查覆盖全池排序后截断、稳定随机、到期优先、旧备份迁移、修改顺序下组生效，以及跨午夜调整每日目标时当前随机队列保持。公网上线结果以本轮 PR 与 Actions 为准。
