# 账号与多设备同步

游客可以立即学习。首页或学习设置中的「登录 / 注册」可创建账号，账号为 3–32 位字母、数字、点、下划线或短横线，密码为 8–128 位。当前未配置短信或邮件服务，不能通过手机号或邮箱找回密码，请使用密码管理器保存。登录状态可维持 30 天，改密会撤销旧会话。

## 换手机

新设备打开同一网址，登录原账号，会恢复词集、每个词的复习计划、词书选择、学习顺序、每日目标及每日学习记录。用到的完整词书会先联网下载；失败时保留本机记录并提供重试。浏览器和未来发布的原生小程序使用同一套账号接口，不需要复制 JSON。微信一键登录仍需独立 AppID，本版使用账号密码。

首次登录可以勾选「合并这台设备上的游客学习进度」。已有云端账号保留云端词书和设置，词集保留双方学过的词，同词冲突取最近一次复习及其完整计划。游客导入没有共同同步基线，为避免同一备份重复累计，每日各判断计数采用两端较大值；这可能少计两份独立游客记录在同一天的累计次数。注册新账号时直接采用本机进度和设置。

## 离线与冲突

登录后仍先保存本机，变更约 1.2 秒后同步；回到页面、恢复网络和每分钟也会尝试同步。离线期间记录保存在当前设备，界面显示未同步状态。只有显示「所有学习记录已同步」后，另一设备才能恢复最新记录；清理存储前请联网同步或导出备份。

同步以每个账号上一次云端快照为共同基线，合并两端改动；不同词的进度同时保留，同词以最近复习为准。每日计数合并双方新增量，词列表去重，设置按字段合并。云端使用递增版本号拒绝过期覆盖；请求编号落盘并去重，避免网络响应丢失导致重复累计。完整复习计划作为一个整体合并，不拼接两个设备的记忆等级。

撤销是当前设备、当前学习操作的能力，不同步撤销栈；真正收到另一设备的进度时，会结束不再可靠的本机撤销。正在进行的学习组保留原顺序，下一组按新进度重新安排。

## 账号隔离和数据控制

退出后恢复本机独立的游客记录，账号缓存与未同步请求分别保存，之后重新登录继续同步。退出需要联网撤销会话；同步失败会保留待同步记录。切换账号不会把上一账号的词集导入新账号。多个网页标签切换账号时，旧标签会停止同步并提示刷新，以免上传到错误账号。

登录时导入备份相当于编辑当前账号的本机进度，下一次同步会合并进云端，请先确认账号。微信端登录状态下禁止「清空游客记录」，需先退出。删除账号需要再次输入密码，永久删除云端账号、会话、进度与去重记录；其他设备的旧登录会失效，本机游客记录保留。

密码经 HTTPS 传输，云端保存独立随机盐和 scrypt 哈希。网页凭证存于 HttpOnly Cookie，原生凭证在微信设备存储中；导出的学习备份不包含登录凭证。云端数据库和部署备份的运维方式见 [部署与维护](deployment.md)。

## 验证

本次功能通过 121 项 Node 自动测试，覆盖学习核心、三方合并、网络重试、账号隔离、持久化中断恢复、原生存储和接口安全。网页原有 18 组交互检查及新增 9 组账号同步检查通过；新增检查以独立浏览器环境模拟新手机，验证完整词书恢复、离线双设备合并、同浏览器双标签页并发、游客隔离和删除账号。微信源码经官方编译器检查，22 个源码页面预览在 320/390 宽度无横向溢出；这不代替真实微信设备验收。
