# 微信小程序导入与正式发布

“一词”是独立项目，不能复用 marathon-platform 的 AppID 或把新代码上传到其已有小程序。参考项目的服务器与 GitHub 自动化可以复用工作方式，小程序主体身份必须独立。

## 本地体验

用微信开发者工具导入本项目的 `miniprogram` 目录，使用测试号或填写属于“一词”的 AppID。代码主逻辑离线运行；游客进度保存在本地，登录账号后同步云端，词库下载后仍可离线使用。浏览器预览可验证交互，但不能代替微信开发者工具和真机验收。

正式 AppID 应写入自己的本地配置，避免在不知情时覆盖既有小程序。原生微信首版仅提供音标，未接授权录音或第三方 TTS；网页朗读使用设备语音。

## 正式微信上传所需材料

- 新小程序注册信息、主体与独立 AppID，以及具备上传权限的管理员/开发者。
- 对应小程序的 CI 上传私钥及后台 IP 白名单（若使用 `miniprogram-ci`）。私钥仅存 GitHub Secret 或开发者私有目录。
- 账号、云端同步和完整词库下载使用 `https://togetherbetter.cn/oneword/api`，后台需把 `https://togetherbetter.cn` 配为合法 HTTPS request 域名；域名及备案等要求以微信后台当时校验为准。当前离线学习不需要在学习流程中收集个人身份。
- 产品隐私说明、所用能力的实际声明、内容和类目审核材料，以及真机体验检查。

服务器部署、H5 发布和 GitHub PR 自动合并，不等于微信公众平台审核通过。未取得以上材料时可以交付可导入源码和在线 H5，但不能声称已生成微信体验版二维码或已在微信正式上线。取得独立 AppID 后，可通过开发者工具上传体验版，再由有权限的管理员提交审核和发布。

## 真机检查建议

在至少一台 iOS 和一台 Android 微信中检查：首次教程、横滑/竖滚区别、三档按钮、更多释义、切词书保持记录、退出重进续学、短时到期、跨日额度、设备安全区及离线使用，以及双设备登录恢复、离线重连合并、改密和注销。卸载小程序/清理缓存可能清除本地记录，应向用户明确备份方式及本地存储边界。

## 离线词库与备份

小程序主包仅含 9 本各 180 词精选（805 个去重词，基础词库约 323 KB），完整词书通过用户主动下载按需缓存。完整书来自源词典标签，合计 14,775 个去重词；SAT 尚未提供。设备缓存采用分片存储，单键和总容量失败时保留旧记录并提示。

备份格式为 `{format:"oneword.backup",version:1,state,bookIds}`，亦兼容旧纯状态备份。备份不附整个词典，换设备恢复需先安装对应词书，依赖本机已有缓存或网络；恢复成功后可离线学习。设备清理数据可能同时删除尚未同步的学习记录和已下载词库，清理前需确认账号同步完成或导出备份。原生账号页面已接入与网页共用的登录/同步 API，真实联网与跨设备登录仍需独立 AppID 后完成微信真机验收。
